# SafeGuard Security

A responsive, single-page security services website developed by TechGlow Solutions.

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Google Apps Script
- Google Sheets
- Google Apps Script MailApp

## Features

- Responsive security services landing page
- Security service and industry information
- Testimonials carousel
- FAQ accordion
- Contact tabs
- Request Quote form
- Backend-verified enquiry submissions
- Google Sheets enquiry storage
- Owner notification and customer acknowledgement emails
- SVG branding and favicon

## Project Structure

- `index.html` — Main website
- `sitemap.html` — HTML sitemap
- `sitemap.xml` — XML sitemap
- `robots.txt` — Crawler configuration
- `assets/css/` — Stylesheets
- `assets/js/` — JavaScript files
- `assets/images/` — Website images and branding
- `PROJECT-DOCUMENTATION.md` — Complete project documentation

## Local Development

Open the project folder in Visual Studio Code and run `index.html` using Live Server.

## Backend

Google Apps Script Web App integrated with Google Sheets and email notifications.

See `PROJECT-DOCUMENTATION.md` for backend configuration and testing details.
